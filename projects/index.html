Vigilens

Architected a multi-agent AI system analyzing live video feeds to detect kitchen safety violations and workflow inefficiencies, delivering real-time actionable insights via a React dashboard. Built backend pipeline integrating TwelveLabs video understanding, custom Health/Efficiency agents, and an interactive Google Docs policy training module.

Predicting League of Legends Game Winners

Engineered scikit-learn preprocessing pipelines over 150,348 observations of professional LoL esports data, isolating features at the 15-minute mark to prevent data leakage. Tuned a Random Forest model using GridSearchCV and 5-fold cross-validation, achieving 74.7% test accuracy (a 12.3% improvement over baseline logistic regression).

View on GitHub

Shopper Intention Prediction

Analyzed 12,330 e-commerce session logs utilizing logistic regression and Welch's t-tests to identify PageValues and BounceRates as critical conversion drivers. Surfaced user intent patterns demonstrating new visitors converted at nearly 2x the rate of returning visitors (25% vs. 14%), generating actionable marketing insights.
